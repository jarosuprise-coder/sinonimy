# Синонимы для Word

Надстройка показывает синонимы к выделенному слову сразу из нескольких словарей, перефразирует фразы и предложения с помощью бесплатных ИИ-сервисов и заменяет текст одним щелчком. Версия 1.4.

- Работает в Word 2019, 2021, 2024 и Microsoft 365 на компьютере, а также в Word в браузере. В Word 2016 панель может не открыться.
- Нужен интернет: панель загружается с сайта https://jarosuprise-coder.github.io/sinonimy

**Скачать:** [Синонимы для Word.zip](https://github.com/jarosuprise-coder/sinonimy/raw/main/%D0%A1%D0%B8%D0%BD%D0%BE%D0%BD%D0%B8%D0%BC%D1%8B%20%D0%B4%D0%BB%D1%8F%20Word.zip) (установщик и инструкция) или только [Установить.cmd](https://github.com/jarosuprise-coder/sinonimy/raw/main/%D0%A3%D1%81%D1%82%D0%B0%D0%BD%D0%BE%D0%B2%D0%B8%D1%82%D1%8C.cmd).

Словари YARN, РуТез и «Большой» разбиты на части по первой букве: панель загружает только нужную часть (от 0,1 до 6 МБ) при первом поиске слова на эту букву и запоминает её.

На вкладке «Все» выше стоят слова, которые есть в нескольких словарях: такие синонимы надёжнее. Повторы убираются без учёта регистра, «ё» и «е», а также окончаний.

## Слова через дефис

Для составных слов вроде «регионально-отраслевая», «научно-технический», «диван-кровать» панель ищет синонимы к слову целиком, а затем к каждой части отдельно и собирает варианты: «местно-отраслевая», «территориально-отраслевая», «научно-инженерный», «диван-кушетка». Окончание второй части подстраивается под исходное слово, первая часть ставится в нужную форму («региональный» → «регионально-», «исторический» → «историко-»). Для прилагательных есть и раздельный вариант: «региональная и отраслевая». Слова с частицами («что-то», «кое-где», «по-русски») так не разбираются.

## Вкладка «✨ ИИ»: перефразирование

Выделите фразу или целое предложение, и в панели откроется вкладка **«✨ ИИ»**. Выберите стиль: **Другими словами**, **Проще**, **Короче** или **Официальнее**. Появятся 3–7 вариантов, а щелчок по варианту заменит выделенное. Кнопка «Ещё варианты» запрашивает новые.

Для одного слова на вкладке «✨ ИИ» появляются синонимы, подобранные по смыслу предложения и в той же форме (падеж, число, время).

Вместе с фрагментом сервису отправляется предложение, в котором он стоит, чтобы варианты подходили по смыслу и грамматике. Каждое нажатие на стиль — один запрос.

| Сервис (⚙ Настройки) | Что нужно | Особенности |
|---|---|---|
| **OVHcloud AI Endpoints** (по умолчанию) | ничего | Llama 3.3 70B и другие открытые модели, ответ за 2–4 секунды; без ключа около 2 запросов в минуту |
| **Pollinations** | ничего | медленно (до 30 секунд), не чаще раза в 30 секунд, качество среднее |
| **Groq** | бесплатный ключ: [console.groq.com/keys](https://console.groq.com/keys) | очень быстро, около 1000 запросов в день |
| **OpenRouter** | бесплатный ключ: [openrouter.ai/keys](https://openrouter.ai/keys) | только бесплатные модели (`:free`), около 50 запросов в день |
| **Google Gemini** | бесплатный ключ: [aistudio.google.com/apikey](https://aistudio.google.com/apikey) | из России нужен VPN |
| **Mistral** | бесплатный ключ: [console.mistral.ai](https://console.mistral.ai/api-keys) | нужно подтвердить телефон |
| **Hugging Face** | бесплатный токен: [huggingface.co/settings/tokens](https://huggingface.co/settings/tokens) | DeepSeek, Qwen, Gemma, Llama; небольшой месячный лимит |
| **Cohere** | бесплатный пробный ключ: [dashboard.cohere.com](https://dashboard.cohere.com/api-keys) | около 1000 запросов в месяц, только некоммерческое использование |
| **SiliconFlow** | бесплатный ключ: [cloud.siliconflow.com](https://cloud.siliconflow.com/account/ak) | бесплатны небольшие модели (Qwen 7–8B, GLM 9B) |
| **Chutes** | ключ: [chutes.ai](https://chutes.ai/app/api) | бесплатный доступ ограничен, условия часто меняются |
| **DeepSeek** | ключ и пополненный баланс: [platform.deepseek.com](https://platform.deepseek.com/api_keys) | не бесплатно, но очень дёшево; бесплатно DeepSeek есть в Hugging Face |
| **Свой адрес** | например Ollama: `http://localhost:11434/v1` | модель на своём компьютере, текст никуда не уходит |

Все сервисы из таблицы отвечают на запросы панели (проверено 22.10.2026). Не подошли и не включены: Cerebras, NVIDIA, GitHub Models, Cloudflare, SambaNova, Scaleway, GigaChat и YandexGPT — они не принимают запросы прямо из панели Word.

Если бесплатный лимит сервиса исчерпан, панель сама подождёт и повторит запрос (до двух раз).

Как подключить ключ: **✨ ИИ → ⚙ Настройки** → выберите сервис → вставьте ключ → «Проверить ключ». Если ключ не работает, панель объяснит причину: ключ скопирован не полностью, у токена нет нужных прав, сервис недоступен из вашей страны или нужно включить бесплатные модели в настройках сервиса. Модель выберется сама, её можно поменять через «Загрузить список». Ключи хранятся только на вашем компьютере и отправляются только выбранному сервису. Лимиты бесплатных тарифов меняют сами сервисы.

## Установка в Word на компьютере (Windows)

1. Закройте Word.
2. Дважды щёлкните **Установить.cmd** (архив можно не распаковывать). Если Windows покажет синее окно «Система Windows защитила ваш компьютер», нажмите «Подробнее» → «Выполнить в любом случае».
3. Откройте Word: на вкладке **Главная** справа появится кнопка **Синонимы**.

Если кнопки нет, откройте **Главная → Надстройки → Надстройки разработчика** и щёлкните «Синонимы». Это нужно один раз.

**Если надстройка перестала открываться**, закройте Word и снова запустите `Установить.cmd`: он заново подключит надстройку и очистит кэш Word. Если установщик пишет, что сайт надстройки не открывается, нужен интернет или VPN.

Как это устроено: установщик — один файл, манифест встроен в него. Он сохраняет `manifest.xml` в `C:\Sinonimy` (если туда нельзя писать — в `%LOCALAPPDATA%\Sinonimy`), подключает надстройку к Word так же, как официальный инструмент Microsoft (`HKCU\Software\Microsoft\Office\16.0\WEF\Developer`, имя — Id надстройки, значение — путь к манифесту), убирает старые подключения, проверяет, что сайт панели открывается, и очищает кэш надстроек Word, если Word закрыт. После установки архив и папку можно удалить. Права администратора не нужны.

Если вы раньше загружали `manifest.xml` в Word в браузере, эта копия тоже видна на компьютере в «Мои надстройки». Для компьютера она не нужна: удалите её там (значок «…» у надстройки → «Удалить»), иначе будет две кнопки.

## Установка в Word в браузере

1. Откройте любой документ в Word в браузере.
2. **Главная → Надстройки → Дополнительные надстройки**.
3. Вкладка **Мои надстройки** → **Отправить мою надстройку** → выберите `manifest.xml`.
4. На вкладке **Главная** появится кнопка **Синонимы**.

Word в браузере иногда забывает надстройки, загруженные вручную. Если кнопка пропала, повторите эти шаги.

## Как пользоваться

1. Нажмите **Синонимы** на вкладке «Главная», и справа откроется панель. При первом запуске она несколько секунд загружает словари (около 3 МБ), потом открывается сразу.
2. Выделите слово двойным щелчком или просто поставьте в него курсор, и в панели появится список синонимов.
3. Вверху панели выберите вкладку: **Все** или отдельный словарь. Число на вкладке показывает, сколько там вариантов. На вкладках словарей синонимы сгруппированы по значениям слова.
4. Щёлкните по синониму, и он заменит слово в тексте. Новое слово остаётся выделенным, поэтому можно перебирать варианты подряд.

Полезно знать:

- Слово можно выделять в любой форме («работой», «говорил», «красивыми»), начальную форму надстройка найдёт сама.
- У прилагательных окончание подстраивается: «красивыми» → «прекрасными», «изящными». Существительные и глаголы вставляются в словарной форме, окончание у них нужно поправить вручную.
- Заглавная буква и ВСЕ ЗАГЛАВНЫЕ сохраняются.
- Если у слова несколько начальных форм («стали» → «стать» или «сталь»), над списком появятся кнопки для переключения.
- Поле поиска вверху панели показывает синонимы к любому слову, а щелчок по варианту вставляет его на место курсора.
- Замена отменяется обычным Ctrl+Z.

## Безопасность

- Ключи ИИ-сервисов хранятся только в панели на вашем компьютере (localStorage) и отправляются только выбранному сервису по HTTPS. На незащищённый адрес `http://` (кроме `localhost`) панель ключ не отправит. Кнопка «Удалить все сохранённые ключи» есть в «⚙ Настройки».
- Сервису уходит только выделенный фрагмент и предложение вокруг него, без остального документа.
- Ответы словарей, Викисловаря и ИИ выводятся в панели только как текст, без HTML, поэтому чужой код в них выполниться не может.
- Надстройке нужно только право «чтение и запись документа»: без него нельзя заменить слово.
- Установщик не требует прав администратора: он сохраняет `manifest.xml` в `C:\Sinonimy`, записывает одну строку в `HKCU\Software\Microsoft\Office\16.0\WEF\Developer` и удаляет только старые записи этой же надстройки.
- Сайт `jarosuprise-coder.github.io` общий для всех репозиториев аккаунта: не публикуйте на GitHub Pages этого аккаунта чужой код, иначе он получит доступ к сохранённым ключам.

## Удаление

Дважды щёлкните **Удалить.cmd** и перезапустите Word.

## Если что-то не работает

- **Кнопки нет после перезапуска.** Проверьте, что закрыты все окна Word (посмотрите значок на панели задач), и откройте Word снова.
- **Панель пишет «Словари не загрузились» или на вкладке стоит «!».** Проверьте интернет, закройте панель и откройте её заново.
- **В окне надстроек две кнопки «Синонимы».** Закройте Word, запустите `Установить.cmd` ещё раз и удалите копию, загруженную через браузер (см. выше).
- **«Ключ не принят» или «ошибка токена» на вкладке «✨ ИИ».** Нажмите в «⚙ Настройки» кнопку «Проверить ключ»: панель покажет точную причину. Частые случаи: у токена Hugging Face нет права «Make calls to Inference Providers»; в OpenRouter не разрешены бесплатные модели (Settings → Privacy); Groq и Gemini недоступны из России без VPN, причём VPN должен работать для всего компьютера, а не только для браузера.
- **Надстройка перестала открываться или Word показывает старую версию панели.** Закройте Word и запустите `Установить.cmd` ещё раз.

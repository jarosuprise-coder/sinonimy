# Синонимы для Word

Надстройка показывает синонимы к выделенному слову и заменяет его одним щелчком.

- Словарь: «Словарь русских синонимов» Н. Абрамова, около 19 тысяч статей (версия [egorkaru/synonym_dictionary](https://github.com/egorkaru/synonym_dictionary), лицензия MIT).
- Работает в Word 2016, 2019, 2021 и Microsoft 365 на компьютере, а также в Word в браузере.
- Нужен интернет: панель загружается с сайта https://jarosuprise-coder.github.io/sinonimy

**Скачать:** [Синонимы для Word.zip](https://github.com/jarosuprise-coder/sinonimy/raw/main/%D0%A1%D0%B8%D0%BD%D0%BE%D0%BD%D0%B8%D0%BC%D1%8B%20%D0%B4%D0%BB%D1%8F%20Word.zip): установщик, манифест и инструкция.

## Установка в Word на компьютере (Windows)

1. Распакуйте архив целиком: правой кнопкой по архиву → «Извлечь все». Из самого архива установка не запустится.
2. Дважды щёлкните **Установить.bat**. В открывшемся чёрном окне должны быть две строки `[OK]`.
   Если Windows покажет синее окно «Система Windows защитила ваш компьютер», нажмите «Подробнее» → «Выполнить в любом случае».
3. Закройте **все** окна Word (сначала сохраните документы) и откройте Word снова.
4. На вкладке **Главная** справа появится кнопка **Синонимы**.

Если кнопки нет, откройте **Главная → Надстройки** (или **Вставка → Мои надстройки**), найдите раздел «Надстройки разработчика» и щёлкните «Синонимы».

Установщик кладёт `manifest.xml` в папку `C:\Sinonimy` и сообщает Word, где он лежит (раздел реестра `HKCU\Software\Microsoft\Office\16.0\WEF\Developer`). Права администратора не нужны.

## Установка в Word в браузере

1. Откройте любой документ в Word в браузере.
2. **Главная → Надстройки → Дополнительные надстройки**.
3. Вкладка **Мои надстройки** → **Отправить мою надстройку** → выберите `manifest.xml`.
4. На вкладке **Главная** появится кнопка **Синонимы**.

Word в браузере иногда забывает надстройки, загруженные вручную. Если кнопка пропала, повторите эти шаги.

## Как пользоваться

1. Нажмите **Синонимы** на вкладке «Главная», и справа откроется панель. При первом запуске она несколько секунд загружает словарь (около 6 МБ), потом открывается сразу.
2. Выделите слово двойным щелчком или просто поставьте в него курсор, и в панели появится список синонимов.
3. Щёлкните по синониму, и он заменит слово в тексте. Новое слово остаётся выделенным, поэтому можно перебирать варианты подряд.

Полезно знать:

- Слово можно выделять в любой форме («работой», «говорил», «красивыми»), начальную форму надстройка найдёт сама.
- У прилагательных окончание подстраивается: «красивыми» → «прекрасными», «изящными». Существительные и глаголы вставляются в словарной форме, окончание у них нужно поправить вручную.
- Заглавная буква и ВСЕ ЗАГЛАВНЫЕ сохраняются.
- Если у слова несколько начальных форм («стали» → «стать» или «сталь»), над списком появятся кнопки для переключения.
- Поле поиска вверху панели показывает синонимы к любому слову, а щелчок по варианту вставляет его на место курсора.
- Замена отменяется обычным Ctrl+Z.

## Удаление

Дважды щёлкните **Удалить.bat** и перезапустите Word.

## Если что-то не работает

- **Кнопки нет после перезапуска.** Проверьте, что закрыты все окна Word (посмотрите значок на панели задач), и откройте Word снова.
- **Панель пишет «Словарь не загрузился».** Проверьте интернет, закройте панель и откройте её заново.
- **Word показывает старую версию панели.** Закройте Word, очистите папку `%LOCALAPPDATA%\Microsoft\Office\16.0\Wef` и откройте Word снова.

## Файлы в репозитории

| Файл | Назначение |
|---|---|
| `Синонимы для Word.zip` | готовый архив для установки |
| `Установить.bat`, `Удалить.bat` | установка и удаление в Word на компьютере |
| `Инструкция.txt` | эта же инструкция в виде текстового файла |
| `manifest.xml` | описание надстройки для Word: кнопка на «Главной» и пункт в меню правой кнопки |
| `taskpane.html`, `taskpane.css`, `taskpane.js` | боковая панель |
| `synonyms.js` | поиск начальной формы, подбор синонимов, согласование окончаний |
| `commands.html` | служебная страница, её требует Word |
| `assets/` | иконки |

Если изменить файлы панели в репозитории, изменения сами появятся во всех версиях Word: переустанавливать надстройку не нужно.

# Синонимы для Word

Надстройка показывает синонимы к выделенному слову (или к слову под курсором) и заменяет его в один клик.
Словарь — «Словарь русских синонимов» Н. Абрамова (около 19 тысяч статей, версия из репозитория
egorkaru/synonym_dictionary, лицензия MIT). Окончания автоматически подстраиваются у прилагательных
(«большими» → «огромными»), остальные слова вставляются в словарной форме.

## Файлы

| Файл | Что это |
|---|---|
| `manifest.xml` | описание надстройки для Word (кнопка на «Главной» и пункт в меню правой кнопки) |
| `taskpane.html`, `taskpane.css`, `taskpane.js` | боковая панель |
| `synonyms.js` | поиск начальной формы, синонимов и согласование окончаний |
| `commands.html` | служебная страница, её требует Word |
| `assets/` | иконки |

Словарь (≈6 МБ) скачивается при первом открытии панели и дальше хранится в браузере.
Если хотите, чтобы надстройка не зависела от чужого репозитория, положите рядом файл
`dictionary.json` из egorkaru/synonym_dictionary — панель сначала ищет его.

## Установка

### 1. Выложить файлы на GitHub Pages

1. Войдите на github.com, нажмите **New repository**, назовите `sinonimy`, тип **Public**, создайте.
2. На странице репозитория: **Add file → Upload files**, перетащите все файлы из этой папки вместе с папкой `assets`, нажмите **Commit changes**.
3. **Settings → Pages**: в поле *Branch* выберите `main` и `/ (root)`, нажмите **Save**.
4. Через 1–2 минуты откройте `https://ВАШ-ЛОГИН.github.io/sinonimy/taskpane.html` — должна появиться панель с поиском.

### 2. Вписать адрес в манифест

Откройте `manifest.xml` в Блокноте, **Правка → Заменить**: `BASE_URL` → `https://ВАШ-ЛОГИН.github.io/sinonimy`
(без косой черты в конце), **Заменить все**, сохраните.

### 3. Подключить в Word в браузере

1. Откройте любой документ в Word Online.
2. **Главная → Надстройки → Дополнительные надстройки** (или **Вставка → Надстройки**).
3. Вкладка **Мои надстройки** → ссылка **Отправить мою надстройку** (Upload My Add-in) → выберите `manifest.xml`.
4. На вкладке **Главная** появится кнопка **Синонимы**, а в меню правой кнопки мыши — одноимённый пункт.

Если однажды кнопка пропадёт (Word Online иногда забывает загруженные вручную надстройки), повторите шаг 3.

## Как пользоваться

- Выделите слово двойным щелчком или просто поставьте в него курсор — справа появятся синонимы.
- Клик по синониму заменяет слово. Новое слово остаётся выделенным, так что можно перебирать варианты подряд.
- Если слово многозначное по форме («стали» → *стать* или *сталь*), над списком будут кнопки для переключения.
- Поле поиска сверху — посмотреть синонимы к любому слову; клик вставит его на место курсора.
